# Engineering Best Practices: Security, Architecture & Performance

This document establishes the official engineering guidelines for applications and repositories managed under `ai-dev-workflow`. All agents, developers, and task definitions must adhere to these patterns to ensure long-term maintainability, security, and performance.

---

## 1. Frontend & Mobile Application Security

### 1.1 Supply Chain & Dependency Hygiene
- **Exact Versioning & Auditing:** Avoid loose semver ranges for mission-critical packages. Regularly audit dependencies (`npm audit`, Knip).
- **Blast Radius Control:** Never commit `.env`, secrets, private keys, or modified lockfiles unexpectedly during automated task execution.
- **Isolated Build Environments:** Containerize builds and sandbox third-party dependency installations.

### 1.2 Cross-Site Scripting (XSS) Prevention
- **Context-Aware Sanitization:** Do not use `dangerouslySetInnerHTML` or raw DOM injection unless sanitized through the `Sanitizer API` or `DOMPurify`.
- **Content Security Policy (CSP):** Enforce strict CSP headers, nonce-based script execution, and disable `unsafe-inline` / `unsafe-eval`.
- **AI Payload Defense:** When rendering text or markdown generated by LLMs or external agents, treat the content as untrusted user input; sanitize HTML before rendering to prevent prompt-injected XSS.

### 1.3 Request Integrity & Access Control (OWASP Top 10)
- **SameSite Cookies & CSRF:** Use `SameSite=Lax` or `SameSite=Strict` on session cookies. For state-changing requests, validate custom headers (`X-Requested-With`) and `Origin`/`Referer`.
- **Broken Access Control (IDOR / BOLA):** Never rely on client-side UI hiding as an authorization mechanism. Authorization must be strictly enforced on the server/API layer.
- **Clickjacking Defense:** Set `X-Frame-Options: DENY` or `frame-ancestors 'none'` in CSP.

### 1.4 Runtime Validation at the Edge
- **Parse, Don't Validate:** Validate all incoming data (API responses, search params, form inputs, local storage) at the application boundary using **Zod** (`Schema.safeParse()`). Trust types inside the application only after parsing.

## 2. Component Communication & State Architecture

When sharing data between components, select the tool based on **distance** and **data persistence**:

```text
Distance & Scope                Recommended Pattern / Tool
---------------------------------------------------------------------
Adjacent / Parent-Child         -> Props & Callbacks + Lifting State Up
Deep Nesting (Prop Drilling)    -> Component Composition (children / slots)
Local to Component              -> Colocation (keep state as low as possible)
Imperative Action (Play/Focus)  -> ref + useImperativeHandle
View Snapshot / Filters / Tabs  -> URL State (nuqs: useQueryState)
Server / Remote Data            -> TanStack Query Cache (useQuery + queryOptions)
Global Client State             -> Zustand / Jotai (with useShallow)
Rare Global Config (Theme/Auth) -> React Context (memoized value)
Ephemeral Signal (Toasts)       -> Event Bus (EventTarget / CustomEvent / mitt)
```

### 2.1 Component Composition over Boolean Props
- Avoid boolean prop explosion (`hasHeader`, `isLarge`, `showAction`).
- Use compound components and render props to invert control cleanly:
  ```tsx
  <Dialog>
    <Dialog.Header title="Confirm" />
    <Dialog.Content>{children}</Dialog.Content>
    <Dialog.Actions onConfirm={handleConfirm} />
  </Dialog>
  ```

### 2.2 Server State vs. Client State
- **Do not store backend responses in Redux/Zustand:** Server data is remote, asynchronous, and goes stale. Manage it with **TanStack Query**.
- **`queryOptions` Factory Pattern:** Group queries under domain objects instead of writing custom hook wrappers:
  ```tsx
  export const userQueries = {
    all: () => queryOptions({ queryKey: ['users'], queryFn: fetchUsers }),
    detail: (id: string) => queryOptions({ queryKey: ['users', id], queryFn: () => fetchUser(id) }),
  };
  ```
- **Type-Safe Conditional Queries:** Use `skipToken` instead of non-null assertions:
  ```tsx
  const { data } = useQuery({
    queryKey: ['user', userId],
    queryFn: userId ? () => fetchUser(userId) : skipToken,
  });
  ```
- **Request Cancellation:** Always forward `signal` from query functions to `fetch()` for search-as-you-type and rapidly changing parameters.

### 2.3 URL as the Single Source of Truth
- For any state representing the current view (pagination, search terms, active tabs, filters), sync directly with URL parameters using `nuqs`.
- Ensure links are bookmarkable, shareable, and compatible with browser back/forward history.

## 3. Hydration & Rendering Strategies

### 3.1 Choosing the Right Rendering Model
1. **Static Site Generation (SSG) / ISR:** For content-heavy, publicly cacheable pages (marketing, documentation, blog).
2. **Streaming SSR with Suspense:** Stream fast content immediately (`<Suspense fallback={<Skeleton />}>`) so slow queries do not block initial paint.
3. **Islands Architecture (Astro):** Ship 0 KB JavaScript by default; hydrate only explicitly marked interactive widgets (`client:visible`, `client:load`).
4. **React Server Components (RSC):** Keep database queries, secret handling, and non-interactive layout code strictly on the server. Guard against `"use client"` creep.
5. **Partial Pre-Rendering (PPR) / Cache Components:** Serve static shells instantly from CDN edge while streaming dynamic personalization slots.

### 3.2 Hydration Mismatch Safeguards
- Never render client-only globals (`window.innerWidth`, `localStorage`, `new Date().toLocaleTimeString()`) directly in the initial server render pass.
- Use mounted state guards (`useEffect` / `useSyncExternalStore`) or `suppressHydrationWarning` on intended dynamic nodes.

## 4. Mobile Engineering (React Native & Expo)

### 4.1 UI Thread & 60/120 FPS Performance
- **Virtualization:** Use `@shopify/flash-list` for all large lists with `estimatedItemSize` and memoized item components (`React.memo`).
- **GPU-Accelerated Animations:** Animate only `transform` and `opacity` using `react-native-reanimated`.
- **Native Gesture Handling:** Use `GestureDetector` from `react-native-gesture-handler` instead of JS-bridged touchables.
- **Image Optimization:** Use `expo-image` for hardware-accelerated decoding, memory caching, and progressive placeholders.

### 4.2 Native Verification & Safe Areas
- Always wrap scrollable layouts with `react-native-safe-area-context`.
- Ensure native Android bundle builds succeed via `npm run build:android:local` before committing.
- Verify user flows declaratively with **Maestro** E2E test suites (`npm run verify-mobile`).

## 5. Indispensable Tooling & Code Quality

1. **[Knip](https://knip.dev):** Run `npx knip --production` to detect and eliminate dead code, unused exports, and orphaned packages.
2. **[ts-pattern](https://github.com/gvergnaud/ts-pattern):** Enforce exhaustive pattern matching for discriminated unions (`.exhaustive()`) to prevent missing case bugs.
3. **[Orval](https://orval.dev):** Automatically generate typed React Query clients and Zod schemas from backend OpenAPI specs to eliminate schema drift.
4. **[Zod](https://zod.dev) / [Valibot](https://valibot.dev):** Enforce strict runtime schema validation at the application boundary.
5. **[Biome](https://biomejs.dev):** High-speed linter and formatter to keep formatting and static analysis instant across the repository.
